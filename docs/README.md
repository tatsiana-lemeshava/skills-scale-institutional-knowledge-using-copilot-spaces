# OctoAcme Project Management

Welcome to the documentation hub for OctoAcme's project management processes. This README introduces our approach and serves as a directory to all major process docs.

## Project Management Processes Summary

OctoAcme follows a structured, iterative project management methodology based on industry best practices:

- **Initiation**: Defining project goals, scope, and stakeholders
- **Planning**: Creating timelines, resource plans, and milestones
- **Execution & Tracking**: Daily management, stand-ups, and tracking progress
- **Risk & Communication**: Identifying risks, escalation paths, and communication plans
- **Prototyping**: Create prototype of application with UI and partialy working functionality
- **Release & Deployment**: Procedures for releases and go-lives
- **Retrospective & Improvement**: Post-release reviews and continuous improvement

## Getting Started

- **New to OctoAcme?** Start with the [Project Management Overview](./octoacme-project-management-overview.md) for a concise introduction.
- **Starting a new project?** Follow the [Project Initiation Guide](./octoacme-project-initiation.md), then the [Project Planning](./octoacme-project-planning.md) doc.
- **Currently executing?** Use [Execution & Tracking](./octoacme-execution-and-tracking.md) and [Risk Management & Communication](./octoacme-risks-and-communication.md) for day-to-day guidance.
- **Preparing to release?** Consult the [Release & Deployment Guide](./octoacme-release-and-deployment.md).
- **Wrapping up a project?** Run a [Retrospective](./octoacme-retrospective-and-continuous-improvement.md) to capture learnings.

## How to Use These Docs

- Keep the Project Charter updated in your project repo

- Reference these docs in issue templates, PRs, and project kickoffs to ensure consistency
- Update and iterate these docs based on team feedback—they are living documents
